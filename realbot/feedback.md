# bot 出现了问题怎么办
## 反馈问题
前往 GitHub 仓库的 issues 创建一个 issue：https://github.com/BlockG-ws/realbot/issues

在创建 issues 前，请确保你已阅读了 [已知问题](/realbot/known-bugs)，并且搜索过已有的 issues 以便确定问题存在解决方案。

## 帮忙修复
直接前往 GitHub 仓库开启 pull request 即可

或者可以通过邮箱等方式向我发送 patch，要创建一个 git patch，可以参考：

https://stackoverflow.com/questions/5159185/how-to-create-a-git-patch-from-the-uncommitted-changes-in-the-current-working-di
